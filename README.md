# Tabs-Component
This project implements a simple and responsive Tabs Component using HTML, CSS, and JavaScript. Tabs allow users to switch between multiple content sections without reloading the page, improving user experience and interface organization.

# Tabs Component (HTML, CSS, JavaScript)

## 📌 Overview
This project is a simple tabs interface built using pure HTML, CSS, and JavaScript. It allows users to switch between different content sections by clicking on tabs

## 🚀 Features
- Interactive tab switching
- Active tab highlighting
- Clean and responsive design
- Lightweight (no external libraries)


## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)


## 📂 Project Structure
tabs-project/
│── index.html
│── style.css
│── script.js
│── README.md

## ⚙️ How It Works
1. Each tab button has a data-tab attribute.
2. When a button is clicked:
   - All tabs are deactivated
   - The clicked tab is activated
   - The corresponding content is shown
3. JavaScript handles the switching logic using event listeners.


## ▶️ How to Run
1. Download or clone the project
2. Open index.html in any browser

## 📸 Output
- Displays multiple tabs (Tab 1, Tab 2, Tab 3)
- Clicking each tab shows different content
